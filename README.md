Academic Workload Management System

Program berbasis C++ yang dibuat untuk membantu mahasiswa mengatur tugas kuliah, memantau deadline, dan menentukan tugas yang harus dikerjakan terlebih dahulu.

Tentang Program

Mahasiswa sering kesulitan mengatur banyak tugas dari berbagai mata kuliah. Akibatnya, beberapa deadline bisa terlewat atau pengerjaan tugas menjadi tidak teratur.
Program ini dibuat sebagai solusi sederhana untuk mencatat tugas, mengurutkan deadline, dan memantau progres pengerjaan.

Fitur Utama

- Tambah Tugas: Mencatat nama mata kuliah, nama tugas, dan deadline.
- Daftar Tugas: Melihat seluruh tugas yang sudah dicatat.
- Deadline Reminder: Memberikan peringatan untuk tugas yang mendekati deadline atau terlambat.
- Prioritas Tugas: Mengurutkan tugas berdasarkan deadline terdekat menggunakan Bubble Sort.
- Status Tugas: Mengatur status tugas menjadi belum dikerjakan, sedang dikerjakan, atau selesai.
- Edit dan Hapus: Mengubah atau menghapus data tugas.
- Statistik Akademik: Melihat jumlah tugas dan persentase penyelesaiannya.

Materi C++ yang Digunakan

- Struct
- Array Dinamis (Vector)
- Seleksi Kondisi
- Looping
- Function
- Enum
- Bubble Sort

Teknologi

- Bahasa C++
- Visual Studio Code
- Standard Template Library (STL)

Catatan

Program masih berjalan melalui terminal dan data tugas belum tersimpan secara permanen. Pengembangan berikutnya direncanakan menggunakan File Handling agar data tidak hilang ketika program ditutup.
